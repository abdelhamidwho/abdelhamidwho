## Abdelhamid Ramadan

**Senior Mobile Software Engineer — Kotlin Multiplatform focus**

I build production healthcare apps at IDH (Integrated Diagnostics Holdings) in Cairo, shipping across the Almokhtabar, Alborg and Alborg Scan brands — products that patients and lab staff depend on every day.

My work sits where Android depth meets shared-code pragmatism: Kotlin and Jetpack Compose on native Android, and Kotlin Multiplatform with Compose Multiplatform when a feature deserves to exist once instead of twice. I care about architecture that survives handover — clear module boundaries, testable layers, and code the next engineer can read without a guided tour.

I also run **Kheprx**, a small software house taking client products from idea to store.
